# Retail Store Sales Dashboard

## Introduction

This project presents an interactive Power BI dashboard designed to analyze retail store sales performance. The dashboard provides valuable insights into sales trends, customer activity, product categories, payment methods, and business performance to support data-driven decision-making.

## Dashboard Insights

- Butchers generated the highest sales among all product categories.
- Cash was the most frequently used payment method.
- Sales peaked in January before stabilizing throughout the year.
- Online and In-store sales showed similar performance.
- Item_25_FUR recorded the highest sales among all products.
